# Assignment Grading System

A mini coding project built during my free time that utilises Python to build a command-line application designed with features like:
*   Student article submissions
*   Grading operations
*   User authentication

## Prerequisite for Execution
*   Python 3.x environment
*   Run the main script to execute the program!

## System Architecture
The project explores the concept of Object-Oriented Programming (OOP) principles in Python. 

* **Language:** Python 3.x
* **Design Paradigm:** Object-Oriented Programming (OOP)
* **Data Storage:** JSON
* **Interface:** Interactive Command-Line Interface (CLI)

## Core Features

* **User Authentication:** Valid credentials are required before users can operate the system.
* **Submission Tracking:** Full CRUD-style operations to add, view, and permanently delete specific student assignments.
* **Grading System:** Allows authorized users to assign and modify scores for individual student submissions.
